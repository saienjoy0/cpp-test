# 2026 程序设计 II - 第12周课后选择题

## 主题
虚函数与运行时多态

## 知识点

- virtual 函数
- 运行时多态
- override
- overload / override / hiding 区别
- 静态绑定与动态绑定
- 静态类型与动态类型
- 基类指针/引用调用派生类虚函数
- 对象切片（object slicing）
- 按值传递与多态
- 函数重载与返回值限制

## 重点

### 运行时多态条件

1. 基类函数声明为 virtual
2. 派生类重写同签名函数
3. 使用基类指针或引用指向派生类对象

### override

基类：
```cpp
virtual void func();
```

派生类：
```cpp
void func();
```

仍然保持虚函数性质。

### 静态绑定

编译阶段决定调用函数。

### 动态绑定

运行阶段根据对象实际类型决定调用哪个虚函数。

### 注意

普通函数通过基类对象传递会发生对象切片：
- 只保留基类部分
- 不产生动态多态

引用或指针传递可以保持多态行为。
