主要知识点：

- ADT 由声明部分和实现部分组成。
- class 默认成员访问权限为 private。
- struct 默认成员访问权限为 public。
- C++ struct 可以包含成员函数。
- const 成员函数不能修改数据成员。
- 类内部定义的成员函数默认 inline。
- 对象是类的实例。
- 信息隐藏通常使用 private 数据成员和 public 接口。
- 多文件编译中类声明通常放在 .h / .hpp 文件。
- 外部定义成员函数需要使用作用域解析运算符 `::`。
