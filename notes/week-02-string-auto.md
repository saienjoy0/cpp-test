主要知识点：

- std::string 相比 C 风格字符串的优势：自动管理内存，降低手动管理风险。
- string 初始化 `string s("hello");` 是构造函数调用。
- 字符串长度：`size()` / `length()`。
- 查找子串：`find()`。
- `operator[]` 返回字符引用，可以作为左值修改。
- 函数重载：函数名相同，参数列表不同。
- constexpr：用于编译期求值。
- auto：编译期间根据初始化表达式推导类型。
- C++11 引入的新特性。
